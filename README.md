# 🍷 Wine Quality Prediction — Machine Learning Project
## 📌 Visão Geral

Este projeto tem como objetivo prever a qualidade de vinhos com base em características físico-químicas, utilizando técnicas de Machine Learning.

A metodologia utilizada foi o CRISP-DM (Cross Industry Standard Process for Data Mining), garantindo uma abordagem estruturada e alinhada às boas práticas do mercado.

## 🧠 Metodologia: CRISP-DM

O projeto foi desenvolvido seguindo as etapas do CRISP-DM:

* Business Understanding
* Data Understanding
* Data Preparation
* Modeling
* Evaluation

## 1️⃣ Business Understanding
🎯 Problema de Negócio

Produtores de vinho precisam classificar a qualidade do produto para:

* Ajustar processos de produção
* Melhorar padrões de qualidade
* Reduzir perdas
* Direcionar estratégias de mercado

📌 Objetivo Técnico

Desenvolver um modelo capaz de prever a qualidade do vinho com base em suas propriedades químicas.

## 2️⃣ Data Understanding
📊 Dataset

O dataset contém variáveis físico-químicas como:

* Fixed acidity
* Volatile acidity
* Citric acid
* Residual sugar
* Chlorides
* Free sulfur dioxide
* Total sulfur dioxide
* Density
* pH
* Sulphates
* Alcohol

Variável alvo:

* Quality

🔎 Principais análises exploratórias realizadas:

* Estatísticas descritivas
* Verificação de valores nulos
* Análise de distribuição
* Correlação entre variáveis
* Identificação de outliers

## 3️⃣ Data Preparation
🔧 Tratamentos aplicados

* Verificação e tratamento de dados ausentes
* Padronização das variáveis numéricas
* Análise e possível tratamento de outliers
* Separação em treino e teste
* Balanceamento com SMOTE
* Pipeline reprodutível de transformação

## 4️⃣ Modeling
🤖 Modelos aplicados

* Random Forest

⚙️ Estratégias utilizadas

* Split treino/teste
* Validação cruzada
* Ajuste de hiperparâmetros

## 5️⃣ Evaluation
📈 Métricas avaliadas

* Accuracy
* Precision
* Recall
* F1-score
* Matriz de confusão

📌 Principais Insights

* Identificação das variáveis mais relevantes
* Análise de erros (falsos positivos e falsos negativos)
* Avaliação do impacto dos modelos base e com hiperparametros aplicados

* NumPy
* Matplotlib / Seaborn
* Scikit-learn
* ImbLearn
